# Sentinel workspaces

| Capability | Branch manager | Fraud investigator | Data engineer |
| --- | --- | --- | --- |
| Business overview, reports and transaction trends | Yes | Yes | Yes |
| Plain-language pattern comparison | Yes | Yes | Yes |
| Historical replay monitor | No | Yes | Yes |
| Import data and warehouse administration | No | No | Yes |
| Dataset dictionary and star schema | No | No | Yes |
| CART, K-means and Apriori lab and training | No | No | Yes |
| SQL, model versions and technical diagnostics | No | No | Yes |
| Demo alert previews and simulated shift scenario | No | No | Yes |

Each workspace names the role and its responsibilities. Manager and investigator Help explains only their tasks and how to interpret labels, flags, simulation time and pattern changes. Navigation and direct route access follow the same role configuration. API middleware enforces engineer-only learning, import, administration and rule-mining endpoints. OLAP responses omit SQL for other roles. Historical replay remains explicitly labelled and does not represent a live bank feed.

## Design references

- Conceptzilla, Finance Analytics Dashboard: https://dribbble.com/shots/25765497-Finance-Analytics-Dashboard
- Phenomenon Studio, NeuroBank: https://dribbble.com/shots/26127078-NeuroBank-Online-Banking-Dashboard-Design

The references informed navigation hierarchy, clear analytical panels, restrained colour accents and task-focused views. Sentinel uses original layouts and existing local images; it does not reuse the designers' assets.
